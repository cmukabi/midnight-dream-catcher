# 🌙 The Midnight Dream Catcher (Mobile PWA)

An ultra-dim, bedside Progressive Web App designed as a mobile companion to **The Creative Sandbox**. Engineered to capture fleeting dreams at midnight before they evaporate—turning half-asleep voice notes into written logs and cinematic storyboard frames.

## ✨ Key Features

- **Zero-Glare OLED Midnight UI:** Pitch-black background (`#000000`) with warm, eye-safe amber typography so waking up in the dark never hurts your eyes.
- **One-Tap Midnight Voice Dictation:** Uses the native Web Speech API to transcribe spoken dreams hands-free straight into your dream log.
- **Local Dream Archive:** Automatically timestamps and saves every dream entry privately in your phone's local browser storage.
- **AI Storyboard Visualizer (Optional):** Connect an OpenAI API key in Settings to generate cinematic storyboard frames directly from your dream transcripts.
- **Installable Mobile App:** Add directly to your iPhone or Android Home Screen for full-screen, app-like access with zero app store downloads required.
